保存先はこのブラウザー内です。通信・アカウント・課金はありません。保存と書出しは、このデモ側の機能です。

できることと、任せていないこと

変更した項目の現在値を確認してから、逆の変更を適用します。他の項目に入った後の編集は、まとめて巻き戻しません。保存先や利用者の権限、対象文書の同一性は、利用するアプリ側で扱います。

別の変更と衝突したら？

B案を作ったあと、先にベースをC案へ変更してください。その状態で「ベースだけA案へ戻す」を押すと、現在値が一致しないため戻さずにC案を保持します。
